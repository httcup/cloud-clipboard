☁️ 云便签

免登录的云端 Markdown 笔记本：多页笔记、实时预览、截图粘贴、跨设备同步。

使用方法非常简单：

  1. 在上方输入一个您喜欢的名字（例如 demo），点击“打开笔记”。
  2. 或者直接在浏览器地址栏输入 note.139t.cn/demo。
  3. 您将进入笔记页面，在文本框中输入内容，内容会自动保存到云端。
  4. 在其他设备上访问相同的网址，即可看到您刚才输入的内容。

URL 结构

https://note.139t.cn/您的名字

名字可以是字母、数字或中文。只要名字相同，就能进入同一个笔记空间。

支持 Markdown 实时预览、截图粘贴上传、分享二维码与访问密码。数据 30 天未更新自动清理，请勿存放敏感永久资料。
